# Лабораторная работа №1 по Дискретной математике

Программа для анализа булевых формул: построение таблицы истинности, СДНФ, СКНФ, нахождение фиктивных переменных, представление формулы в различных функционально полных базисах и построение полинома Жегалкина.

## Формат входных данных

На вход подаётся текстовый файл, содержащий логическую формулу.

Пример формулы:
```
($A [^] $B)
```

### Правила синтаксиса:
- Переменные и константы предваряются символом `$`:
  - Имена переменных — латинские буквы (`$A`, `$b`, `$x` — регистр не имеет значения, `$a` эквивалентно `$A`).
  - Логические константы: `$0` и `$1`.
- Операторы заключаются в квадратные скобки `[...]`.
- Допускается использование круглых скобок `(` и `)`.
- Пробельные символы игнорируются.

### Поддерживаемые операторы (в порядке убывания приоритета):
1. `[!]` (приоритет 6, ассоциативность справа налево) — логическое НЕ (NOT)
2. `[*]` (приоритет 5, слева направо) — логическое И (AND, конъюнкция)
3. `[!*]` (приоритет 5, слева направо) — штрих Шеффера / И-НЕ (NAND)
4. `[^]` (приоритет 4, слева направо) — исключающее ИЛИ (XOR, сложение по модулю 2)
5. `[+]` (приоритет 3, слева направо) — логическое ИЛИ (OR, дизъюнкция)
6. `[!+]` (приоритет 3, слева направо) — стрелка Пирса / ИЛИ-НЕ (NOR)
7. `[->]` (приоритет 2, слева направо) — импликация
8. `[!->]` (приоритет 2, слева направо) — коимпликация (запрет по B / A and not B)
9. `[=]` (приоритет 1, слева направо) — эквивалентность (XNOR)

## Флаги запуска

- `--pdnf` — вывод СДНФ (Совершенной дизъюнктивной нормальной формы)
- `--pcnf` — вывод СКНФ (Совершенной конъюнктивной нормальной формы)
- `--fictive` — определение и вывод фиктивных переменных
- `--different_basis` — представление формулы в функционально полных базисах:
  - {AND, OR, NOT}
  - {NOR} (стрелка Пирса)
  - {NAND} (штрих Шеффера)
  - Построение полинома Жегалкина (базис {XOR, AND, 1}) методом треугольника Паскаля

## Компиляция (без Makefile)

Для сборки проекта используется стандартный компилятор `gcc`:

```bash
gcc -Wall -Wextra *.c -o truth_table
```

## Примеры использования

```bash
# Базовый вывод таблицы истинности
./truth_table input.txt

# Вывод со всеми флагами
./truth_table --pdnf --pcnf --fictive --different_basis input.txt
```
